## Markdown の画像 — 実測で決めました

前半の宿題です。まず測りました。

| 書き方 | 出力 |
|---|---|
| `![図](./diagram.png)` | `<img width="1200" height="675" loading="lazy" …>` |
| `![図](/og.png)` | `<img src="/og.png" alt="…">` |

**相対パスなら Astro が寸法を付けます。** 絶対パス（`public/` 直下）は素通しです。

### sharp を入れませんでした

Astro の既定の画像サービスは sharp（native モジュール）を要求し、
入っていないとビルドが落ちます。

`passthroughImageService()` に切り替えたところ、**寸法は付いたまま**でした。

```
<img alt="レイアウトの図" loading="lazy" width="1200" height="675" src="/_astro/diagram….png">
```

失うのは webp 変換だけで、**ずれないことは保てます。**
native の依存を増やさない方を選びました（OS を選ばない、という性質にも関わります）。
最適化が欲しくなったら sharp を足すだけで切り替えられます。

## 検査の作り直し 3 件

### 1. 画像の場所取り: 推測 → 実測

前半で足した「場所を取っていない画像」の判定は、**まったく機能していませんでした。**
寸法の無い画像を置いて走らせても 0 件です。

原因は、属性と computed style から推測していたことです。
画像が届いてしまえば高さは確定するので、測るときには
「ちゃんと場所を取っている画像」と区別が付きません。
ローカルのプレビューは速いので、常に届いた後でした。

**画像のリクエストを遮断してから開く**方式に変えました。
利用者が遅い回線で見るのと同じ状態です。

そこでもう一段引っかかりました。**高さの数値では区別できません。**

```
届かなかった画像（場所なし）: 30px  ← 代替テキストの高さ
CSS で h-8 を指定した画像    : 32px  ← 同じくらいの数字
```

代替テキストを一時的に空にして、高さが消えるかで判定します。

```
場所を取っていない画像:  30px → 16px（壊れた画像の枠だけ）
場所を取っている画像  : 185px → 185px（変わらない）
```

24px を境にすれば確実に分かれます。

### 2. `flex-shrink: 0` の判定が縦並びでも効いていた

`/contact/` の段組みが 375px と 414px で引っかかりました。

```
✗ 画面幅より縮まない要素: 1 件 (div 343px)
```

中身を見ると `Column`（`wt-col--sized`）で、はみ出してはいません。
**flex-shrink は主軸の縮み方の指定**なので、親が縦並びに畳まれていれば
それは高さの話で、幅とは関係ありません。

親が横並びのときだけ見るようにしました。
狭い画面で畳む段組みは、これから毎回引っかかるところでした。

### 3. 雛型ページの骨格を判定に追加

雛型は「見た目」ではなく「骨格」を配るものなので、骨格を判定にしました。

```
✓ /lp/ h1 がちょうど 1 つ  (1 個)
✓ /lp/ landmark が揃っている（header / main / footer）
✓ /lp/ スキップリンクの飛び先が focus できる
✓ /lp/ 見出しが飛び級していない  ([1,2,3,3,3,2,2,2,2])
```

見出しの飛び級（h1 の次が h3）は、読み上げの目次が壊れる合図です。
目で見ても分かりません。

## 作った雛型

| ページ | 中身 |
|---|---|
| `/lp/` | ヒーロー（`Frame` + `Image`）/ 特徴 3 つ / FAQ（`<details>`）/ CTA |
| `/about/` | `<dl>` の基本情報 / `<ol>` + `<time>` の沿革 / `<address>` |
| `/contact/` | フォームだけ island。残りは静的 HTML |

**見た目のセクション集は作っていません。** 用意したのは、
初心者が必ず抜かすのに見た目には出ないものです。

- 見出しの階層（`h1` は 1 つ、飛び級しない）
- landmark（`header` / `main` / `footer` / `nav`）とスキップリンク
- 画像が場所を先に取っていること
- FAQ が JavaScript 無しで開くこと
- 項目と値は `<dl>`、沿革は `<ol>` + `<time>`、住所は `<address>`

ナビとフッタの定義は `src/lib/nav.ts` の 1 か所です。
ページごとに書くと「新しいページを足したのにヘッダから辿れない」が起きます。
