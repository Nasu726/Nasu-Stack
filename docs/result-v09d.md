## 直したこと

### 段組を畳んだときの向き（配布物）

`Columns` は畳むと `flex-col` になりますが、`alignY`（`items-start`）が
そのまま残っていました。**列方向では `items-*` は横方向の指定**なので、
幅を持たない列が中身の幅まで縮みます。

`alignY` を**横並びになる幅でだけ**当てるようにしました。

**最初に思いついた直し方は間違いでした。** `.wt-col{width:100%}` を当てたら
行方向が壊れ、`auto` の列が 0px になりました（当てて測って気づきました）。

実測: 760px で `auto` の列が **179px → 678px**。1440px は今までどおり（1/3 = 314px）。

### ホイールの向き（配布物）

v0.9c で入れた「縦→横」の変換を**削除**し、**横の動きだけ**を見るようにしました。
コード例や表の上を通っただけでページの縦読みが止まるのが、作者の指摘どおり
害のほうが大きいためです。

`Scrollable` の `axis="x"` から `overflow-y-hidden` も外し、
`Inline wrap={false}`（`wt-nowrap`）と同じ形に揃えました。

判定も入れ替えました。**縦で動かないことも確かめます。**

```
✓ ホイールの横で横スクロールできる  ({"横":120,"縦":0})
✓ ホイールの縦では横に動かない      ({"横":120,"縦":0})
```

### スクロールバーを隠せるように（配布物）

`Scrollable scrollbar="hidden"`。**端の影は残します**——消すと、そこが
スクロールできることを示すものが 1 つも無くなります。
カタログの `Scrollable` の節で切り替えて試せます。

### テーマの保存先（配布物）

`localStorage` は origin 単位なので、`/catalog/` と `/demo/` が同じ入れ物を
共有していました。**利用者が `/app/` と `/docs/` を同じドメインに置いても
同じことが起きます。**

- `ThemeProvider` に `storageKey` と `lockTheme`
- `makeThemeInitScript({ storageKey, lockTheme })`
- `ThemeSwitcher themes={false}` で明暗だけ

デモは**明暗だけ**にしました（作者の判断）。`data-theme` はページが決めた値の
ままです。実測: カタログを vivid+dark にしても `/demo/lp/` は `warm` のまま。

**`client:idle` は使えませんでした。** `requestIdleCallback` はタブが見えて
いないと発火しないので、開いた直後に押しても何も起きないことがあります
（実測で踏みました）。押される場所なので `client:load` にしています。

### カタログのヘッダ（後退の修正）

v0.9c で `max-w-[min(38rem,60vw)]` を `min-w-0 flex-1` に変えました。
半画面は直りましたが、**375px でタブが 13px に潰れました。**

`1024px` 未満は 2 段（ブランド＋トンマナ／タブ）にしました。根拠は実測です。

```
1440px: 器 1024 に対して ブランド 108 + タブ 531 + トンマナ 248 + 明暗 64 = 951
        余り 73px。器が 980 を切ると 1 行には入りません。
```

実測: 375px でタブの可視幅 **13px → 343px**（1 項目 76px）。760px では 728px で
スクロールすら不要。狭いときのヘッダの高さは、余白を詰めて 171px → 155px。

### その他

- ハンバーガーの枠から `overflow-hidden` を外しました（角丸は残ります）
- `dividers` の例が `space="md"` 固定だったので、上のボタンに繋ぎました
  （**部品は正しく、デモが間違っていました**）
- `withBase` の説明に `<img src>` / `<iframe src>` / `fetch` を足しました

## 潰れの検査（指摘 7 への答え）

**これまでの検査は「外へ出ていないか」しか見ていませんでした。**
中へ潰れているものは全部緑のまま通ります。実際、タブの 13px も
`auto` 列の 48px も、Frame の 24px も、1 つも赤くなりませんでした。

`check-responsive.mjs` に**潰れの判定**を足しました。

- 縦に積まれた親の中で、**親の幅の 40% 未満**になっている `.wt-col` / `.wt-frame`
- **スクロールできる器が 1 項目より狭い**もの

これで「全部の部品を 1 つずつ実測する」が、一度きりではなく毎回になります。

### わざと壊して確かめました

```
Columns の畳み方を戻すと → ✗ 場所があるのに潰れている要素: 1 件
                              ↳ <div class="wt-col"> が 48px（親は 238px）
器を 13px にすると        → ✗ tablist（1 項目 76px より狭い）
```

タブ側は、v0.9c の形に戻しただけでは再現しませんでした（新しい枠が
折り返しで逃げるため）。**器の幅を直接 13px にして、判定が鳴ることを確かめて
います**——「戻したら赤くなった」ではないので、そこは正直に書いておきます。
