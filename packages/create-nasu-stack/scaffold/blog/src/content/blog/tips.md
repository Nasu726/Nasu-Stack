題名に `<` と `&` が入っています。**この記事は消さないでおくと便利です。**
記号のエスケープを忘れると RSS が壊れますが、購読している側は
たいてい何も言わずに購読をやめるので、**壊れたことに気づけません。**
1 本置いておけば、`npm run check` のたびに確かめられます。

## `<div>` と `<section>` の違い

`<section>` は「見出しを持つひとまとまり」です。見出しが無いなら `<div>`。
迷ったら `<div>` にしてください。意味の無いところに `<section>` を置くと、
読み上げの目次に空の項目が並びます。

> 意味づけは、迷ったら弱いほうを選ぶ。強い意味づけを間違えるほうが害が大きい。
